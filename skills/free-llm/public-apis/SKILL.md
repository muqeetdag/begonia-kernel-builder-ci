Sports, Tracking, Transportation, URL Shorteners, Vehicle, Video, Weather,
and more.

## How to use

1. Browse the README table by category.
2. Check the **Auth** column (None / apiKey / OAuth) and **HTTPS** column.
3. Open the API's docs, get a free key if needed, and call it.
4. For LLM APIs specifically, prefer the
   [awesome-free-llm-apis](awesome-free-llm-apis/SKILL.md) catalog —
   it's deeper and fresher for AI endpoints.
